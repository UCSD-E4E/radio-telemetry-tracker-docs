# Assets

This directory contains media files used in the documentation.

## Contents

### Diagrams

- [Generated Images](diagrams/img/) - PNG images of diagrams
- [Source Files](diagrams/src/) - PlantUML source files for diagrams

### Images

- [General Images](images/) - Other images used in documentation

## Diagram Sources

The diagrams are created using PlantUML. To modify or regenerate the diagrams:

1. Edit the `.puml` files in the `diagrams/src/` directory
2. Use a PlantUML renderer to generate new PNG files
3. Place the generated PNG files in the `diagrams/img/` directory
